# Actividad: Programación Dinámica en C++

Repositorio con la implementación en C++ de dos problemas resueltos mediante **Programación Dinámica**.

## Archivos del proyecto

- `escaleras.cpp` — Problema de las Escaleras (conteo de formas de subir $N$ escalones dando pasos de 1 o 2).
- `cambio_monedas.cpp` — Cambio Mínimo de Monedas (cantidad mínima de monedas y reconstrucción de la combinación óptima).

## Requisitos

- Compilador de C++ compatible

## Compilación y ejecución

### 1. Problema de las Escaleras
g++ escaleras.cpp -o escaleras
./escaleras

### 2. Cambio de monedas
g++ cambio_monedas.cpp -o cambio_monedas
./cambio_monedas
